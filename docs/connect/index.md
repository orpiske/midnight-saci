# Connect Saci to other systems

These pages tell you how to give steps more tools, report results to other systems, and start runs and investigations from other systems.

## Pages in this section

- [Give steps tools from MCP servers](mcp-servers.md): enable MCP servers for an environment.
- [Report results with outcome actions](outcome-actions.md): call MCP tools after a run, with optional approval.
- [Run plans when code changes](watch-repositories.md): `saci watch` polls Git branches and runs plans.
- [Start investigations from other agents with A2A](a2a.md): the A2A endpoint for investigations.
- [Make scripts available as MCP tools](script-runner.md): the MCP script runner.
- [Email the results of each run](email-run-results.md): a complete outcome action with the script runner.
