# Write test plans

A test plan is a Markdown document with phases, tests, steps and expected results. These pages tell you how to write, reuse and convert plans. A coding agent can do this work for you with the [Saci agent skills](../run-tests/use-agent-skills.md).

## Pages in this section

- [Write a test plan](write-a-test-plan.md): actions, expected results, run blocks, setup and cleanup.
- [Reuse steps with procedures](reusable-procedures.md): share steps between plans with `Follow`.
- [Convert existing test plans](convert-existing-plans.md): convert plans from another format and check that every command is kept.
